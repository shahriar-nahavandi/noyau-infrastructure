# کانتینر زیرساخت سیستم (SysCore)

## معرفی
این پروژه یک زیرساخت بک‌اند کانتینری، سبک و یکپارچه را فراهم می‌کند. در این سیستم از وب‌سرور Caddy به عنوان کنترلر اصلی استفاده شده است تا ترافیک ورودی را به صورت بهینه به ماژول‌های سیستمی و سوکت‌های بک‌اند، تنها از طریق یک پورت هدایت کند.

این معماری مخصوص محیط‌هایی طراحی شده است که نیاز به تجمیع چندین سرویس داخلی پشت یک درگاه واحد دارند و استقرار یکپارچه در پلتفرم‌های ابری مدرن را تضمین می‌کند.

## ویژگی‌ها
- **معماری تک‌پورت:** تمام ماژول‌ها و پل‌های ارتباطی داده تنها از طریق یک پورت خارجی ارتباط برقرار می‌کنند.
- **کنترلر وب مدرن:** استفاده از Caddy برای مسیریابی بهینه و بدون سربار اضافی.
- **رابط عمومی:** نمایش یک صفحه فرود استاندارد (حالت نگهداری) در مسیر اصلی برای بازدیدکنندگان عمومی.
- **مسیریابی ماژولار:** تفکیک دسترسی‌های مدیریتی، بسته‌های داده و سوکت‌ها در مسیرهای مجزا.

## استقرار
ساخت ایمیج کانتینر:
```bash
docker build -t syscore-node .
```

اجرای کانتینر:
```bash
docker run -d --name syscore -p 3000:3000 syscore-node
```

## متغیرهای محیطی
شما می‌توانید تنظیمات داخلی را با استفاده از متغیرهای محیطی زیر شخصی‌سازی کنید:
- `PORT_ADMIN`: پورت داخلی برای ماژول مدیریت (پیش‌فرض: 2053)
- `BASE_PATH`: مسیر دسترسی به پنل مدیریت (پیش‌فرض: /sys_admin_core/)
- `ADMIN_USER`: نام کاربری پیش‌فرض مدیر
- `ADMIN_PASS`: رمز عبور پیش‌فرض مدیر
